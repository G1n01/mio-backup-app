Informativa sulla privacy

mio-backup è uno strumento personale, usato solo dal suo proprietario sul proprio computer.

  • Dati a cui accede: solo i file su Google Drive creati da mio-backup stesso (permesso drive.file). Non può vedere gli altri file del Drive.
  • Uso dei dati: i file del computer vengono cifrati sul computer e caricati sul Google Drive del proprietario, esclusivamente come backup.
  • Condivisione: nessun dato viene inviato, venduto o condiviso con terzi. Non esistono server di mio-backup: i dati passano solo tra il computer e Google Drive.
  • Conservazione: i backup restano sul Google Drive del proprietario finché il proprietario non li elimina. L'accesso si revoca in qualsiasi momento da myaccount.google.com/permissions.

L'uso delle informazioni ricevute dalle API di Google rispetta le Google API Services User Data Policy, inclusi i requisiti di uso limitato.
